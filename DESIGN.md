# DESIGN.md — «Тройка», черновик

Статус: **черновик**. Здесь только то, что уже согласовано. Палитра — в работе, цвета не фиксируем до утверждения. Задача и механика — в [SCOPE.md](SCOPE.md), данные для экранов — строго из [shared/contract.ts](shared/contract.ts).

## Продукт в одной фразе
Заказчик выбирает, кто нужен, город, дату, событие и бюджет — сайт показывает, на что смотреть, до трёх подрядчиков и доказывает каждое слово объяснения фактами из каталога.

## Принципы
1. **Объяснение важнее карточки.** Текст «почему» — главный текст карточки после имени.
2. **Доказательство в тексте.** Проверенные факты (`factsUsed[].verified = true`) подсвечены прямо в объяснении по совпадению `label` с текстом; если совпадения нет — строкой под текстом. Слова подрядчика о себе (`verified = false`) — нейтрально, с пометкой «со слов подрядчика».
3. **Честные исходы.** `found` / `no_category_in_city` / `all_filtered_out` различаются заголовком, иконкой и цветом; пустой результат — всегда словами и цифрами из `funnel` и `summary`, никогда пустой экран или ошибка.
4. **Сравнимость.** Строки критериев (`criteria`) идут в одном порядке во всех карточках одного запроса.
5. **Клиповое внимание.** Одно главное действие на экран, короткие фразы, крупные фото, подробности по раскрытию, одна оркестрованная анимация появления результата вместо анимации каждого блока.
6. **Работа ИИ видна.** Пока идёт подбор — шаги пайплайна из SSE (`criteria` → `filter_step` → `card` → `critic` → `done`), а не спиннер.

## Согласовано

### Шрифт
**Onest** (Google Fonts, одно семейство на всё). Поддерживает казахскую кириллицу (Ә Ғ Қ Ң Ө Ұ Ү Һ І). В Next: `next/font/google`, `subsets: ["cyrillic", "cyrillic-ext", "latin"]`.

### Языки
Интерфейс на трёх языках: **RU / ҚАЗ / EN**, переключатель в шапке. Для текстов от LLM (объяснения, «на что смотреть», `summary`) нужен язык в запросе — предложение для контракта: `MatchRequest.locale: 'ru' | 'kk' | 'en'` и язык в ключе кеша объяснений (требует апрува front и back).
Вёрстка должна выдерживать длинные казахские слова: без фиксированной ширины кнопок, перенос в заголовках разрешён.

### Поиск — «конструктор»
Главный выбор «Кто нужен?» — крупные чипы-иконки категорий (на телефоне горизонтальная лента), под ним поля Город / Дата / Событие / Бюджет, опционально Длительность и Язык, одна главная кнопка. Под формой — 4 демо-запроса из SCOPE, заполняют форму в один клик.

### Фото подрядчиков
- Сгенерированы ИИ (gpt-image-2), люди вымышленные, без текста и логотипов.
- Файлы: `front/public/contractors/{id}.webp`, фронт берёт по `card.id` — контракт не меняется.
- На каждом фото пометка «Фото: ИИ-иллюстрация»; то же в README.
- Нет файла — заглушка (мягкий фон + иконка категории), без битой картинки.

### Страницы
- `/` — клиент: шапка, поиск-конструктор, результат (исход, «на что смотреть», до 3 карточек, кто не вошёл и почему, сравнение с другой датой), «как это работает».
- `/admin` — площадка и жюри: **Подбор** (таймлайн SSE, воронка `funnel` с именами, проверка фактов, JSON ответа), **Каталог** (66 профилей с фото и флагами), **Качество** (доля проверенных фактов, слепой тест, кеш, время ответа).

### Доступность
Контраст текста ≥ 4.5:1, видимый фокус, `prefers-reduced-motion`, `aria-live` для результата, иконки — SVG (без эмодзи), зона нажатия ≥ 44px. Страница не ломается на ширине 360px.
