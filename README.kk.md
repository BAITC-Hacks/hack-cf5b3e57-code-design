## Қалай іске қосу
Тек Docker (Docker Compose v2-мен) қажет. Кілттер қажет емес.

```bash
git clone https://github.com/BAITC-Hacks/hack-cf5b3e57-code-design.git
cd hack-cf5b3e57-code-design
docker compose up --build
```

Бір команда PostgreSQL-ді көтереді, миграцияларды қолданады, сидті (66 мердігер) жүктейді, API мен фронтты іске қосады. Алғашқы жинау бірнеше минут алады.

- Сайт: http://localhost:3000 (іріктеу — http://localhost:3000/match)
- API: http://localhost:3001/api/v1/health → `{"ok":true,"mock":true}`

Тоқтату және базаны тазалау: `docker compose down -v`.

### Орта айнымалыларының мысалы
`.env` файлысыз бәрі жұмыс істейді. Тірі модель үшін [`.env.example`](.env.example) файлын жоба түбіріндегі `.env` файлына көшіріңіз (файл `.gitignore` ішінде), кілтті жазып, `MOCK=0` қойыңыз. Команда сол: `docker compose up --build`.

```env
# .env.example (жоба түбірі, Docker Compose үшін)
MOCK=1                      # 1 — модельсіз; 0 — OpenAI (кілт қажет)
OPENAI_API_KEY=             # міндетті емес
MODEL_MAIN=gpt-4o-mini
CORS_ORIGIN=http://localhost:3000
NEXT_PUBLIC_API_URL=http://localhost:3001
```

Docker-сіз іске қосу үшін бөлек мысалдар бар: [`back/.env.example`](back/.env.example) және [`front/.env.example`](front/.env.example).

```env
# back/.env.example
DATABASE_URL="postgresql://postgres:postgres@localhost:5433/hackaton?schema=public"
PORT=3001
MOCK=1
OPENAI_API_KEY=
MODEL_MAIN=gpt-4o-mini

# front/.env.example
BACKEND_URL=http://localhost:3001
NEXT_PUBLIC_API_URL=http://localhost:3001
```

**Docker әдепкі бойынша кілтсіз жұмыс істейді (`MOCK=1`)**: түсіндірмелер сол тексерілген фактілерден детерминирленген түрде құрылады, желі қажет емес. Тірі модель үшін `OPENAI_API_KEY` айнымалысын орта арқылы беріп, `MOCK=0` орнатыңыз; кілтті репозиторийге жазбаңыз.

### Тірі модельмен іске қосу (қалауыңыз бойынша)
Node.js 22+ қажет. База Docker-де қалады, бэк пен фронт жергілікті іске қосылады:

```bash
docker compose up -d postgres
cd back
cp .env.example .env        # OPENAI_API_KEY жазып, MOCK=0 орнату
npm install
npx prisma migrate deploy
npx prisma db seed
npm run start:dev           # API: http://localhost:3001
```

Екінші терминалда:
```bash
cd front
cp .env.example .env.local
npm install
npm run dev                 # http://localhost:3000
```

### Орта айнымалылары
| Айнымалы | Қайда | Не үшін | Міндетті ме |
|---|---|---|---|
| `DATABASE_URL` | `back/.env` | PostgreSQL-ге қосылу | иә, мәні `back/.env.example` ішінде |
| `PORT` | `back/.env` | API порты | жоқ, 3001 |
| `OPENAI_API_KEY` | `back/.env` / Compose ортасы | `MOCK=0` кезінде модельмен тірі түсіндірмелер мен чат | **жоқ** — кілтсіз MOCK жұмыс істейді |
| `MODEL_MAIN` | `back/.env` | OpenAI моделі | жоқ, `gpt-4o-mini` |
| `MOCK` | `back/.env` / compose | `1` — мәжбүрлі түрде модельсіз; кілтпен `0` — OpenAI | жоқ; Docker-де әдепкі `1` |
| `BACKEND_URL` | `front/.env.local` | Next.js сервері үшін API мекенжайы | жоқ, `http://localhost:3001` (Docker-де — `http://backend:3001`) |
| `NEXT_PUBLIC_API_URL` | `front/.env.local` | браузер үшін API мекенжайы (`/manager` бетіндегі стрим) | жоқ, `http://localhost:3001` |

Репозиторийде нақты кілттер жоқ: `.env` және `.env.local` файлдары `.gitignore` ішінде, репозиторийде тек `.env.example`, `back/.env.example` және `front/.env.example` бар.

## Мәселе және кімге арналған
Қазақстандағы іс-шара тапсырыс берушісі өз қаласының мердігерлер каталогын ашып, бір-біріне ұқсас профильдердің арасында адасады: сипаттамалары бірдей («харизма», «топ-10»), неге сену керек және неге қарау керек екені түсініксіз. Алаң менеджері клиентке 3 нұсқаны қолмен жинап, таңдауын түсіндіреді.

**Құндылық сандармен.**
- *Уақыт.* Қазір менеджер бір сұраныс үшін қаладағы санаттың 10–50 профилін ашып, әрқайсысының күнтізбесін, бағасын, форматын және тілін салыстырады. Біздің бағалауымыз бойынша бұл ондаған минут алады. ToiMatch 15–250 мс ішінде жауап береді (кілтсіз режимде өлшенген) және әр нұсқаның неге таңдалғанын, кімнің іріктеуден өтпегенін бірден көрсетеді.
- *Кімге.* Пайданы тезірек таңдайтын тапсырыс беруші және іріктеуді клиенттерге қызмет ретінде енгізетін алаң немесе агенттік алады. Каталог адал нәтиже береді: қолжетімсіз және сәйкес келмейтін мердігерлерді сервис көрсетпейді.

ToiMatch қала, күн, іс-шара түрі, санат және бюджет бойынша **үшке дейін мердігер** қайтарады және әрқайсысы үшін **неге дәл ол екенін түсіндіреді**. Алдымен сервис осы жағдайда **неге қарау керегін** айтады (жүргізу тілі, осындай форматтағы тәжірибе, алаңдағы сағаттар), содан кейін әр карточканы осы тармақтар бойынша түсіндіреді, ал түсіндірмедегі әр факт каталог деректерімен салыстырылады.

## Не іске асырылды
- `POST /api/v1/match` іріктеуі: фактілер бойынша сүзгі, детерминирленген рейтинг, түсіндірмелер, үш айқын нәтиже: `found`, `no_category_in_city`, `all_filtered_out`.
- Алаң экраны үшін пайплайнның қадамдық стримі `GET /api/v1/match/stream` (SSE).
- Сүзгілері бар `GET /api/v1/contractors` каталогы және `GET /api/v1/contractors/:id` профилі.
- PostgreSQL-дегі түсіндірмелер кеші: бірдей сұраныс — бірдей мәтін және рет.
- Іздеу және іс-шараның толық пакеті режимдері бар чат: пакетті жинамас бұрын ең төменгі бюджетті есептейді, бос санаттарды адал көрсетеді, ал қорытынды атаулар мен себептерді модельдің еркін мәтінінен емес, құралдардың нәтижелерінен алады.
- Кілтсіз режим (MOCK): бүкіл сценарий желісіз және біздің аккаунттарымызсыз жұмыс істейді.
- Фронт (Next.js): `/` каталогы, `/match` іріктеуі, `/manager` алаң жұмыс орны (ескі `/admin` мекенжайы сонда бағыттайды), `/contractor/[id]` профилі, `/chat` чат-көмекшісі; интерфейс орыс, қазақ және ағылшын тілдерінде; көмекші маскот Нұрлан.

## Қалай жұмыс істейді — сұраныстан нәтижеге дейін
1. Тапсырыс беруші кім қажет екенін (санат), қаланы, күнді, іс-шараны және бюджетті таңдайды; ұзақтығы мен тілін көрсетуге болады.
2. **Сүзгі (код):** қала → санат → осы күні бос → осы форматты алады → бюджетке сыяды → тіл → сағаттар. Әр қадамда қанша үміткер шығып қалғаны және неге екені есептеледі (воронка).
3. **Рейтинг (код):** сұраныстың өлшенетін критерийлері бойынша детерминирленген рет, тең болған жағдайда — `id` бойынша.
4. **Түсіндірмелер:** сервер себептердің тексерілетін нұсқаларын каталог өрістерінен, басқа карточкалардан айырмашылықтардан және сауалнамалардың нақты үзінділерінен жинайды. OpenAI сәйкес нұсқаны таңдайды, бірақ мердігер туралы еркін мәтін жазбайды; кілтсіз таңдау детерминирленген.
5. **Фактілерді тексеру (код):** себеп көрсету мен кештеуге дейін таңдалған карточкамен салыстырылады. Алмастырылған баға мен сипаттамадан алынған дәйексөздер анық белгіленеді; расталмаған түсіндірме қауіпсіз нұсқамен ауыстырылады.
6. **Жауап:** нәтиже, үшке дейін карточка, воронка және «неге сонша» деген адамша сөйлем.

## Технологиялар, модельдер және API
- Frontend: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Onest қарпі.
- Backend: NestJS 11, Prisma 6, PostgreSQL 16, Docker Compose.
- LLM: OpenAI `gpt-4o-mini` (`MODEL_MAIN` айнымалысы) түсіндірме нұсқасын таңдайды және тексеруге қатысады; кілтсіз — детерминирленген клиент (`back/src/matching/llm/mock-llm.client.ts`). Қорытынды мәтінді әрқашан сервер тексерілген деректерден құрады.
- Суреттер: мердігерлердің фотолары мен маскот OpenAI `gpt-image-2` арқылы жасалған; маскот анимациясы — fal.ai (Kling v3); логотип — fal.ai (Recraft V4.1, SVG).
- Фронт пен бэктің ортақ типтер келісімшарты: [`shared/contract.ts`](shared/contract.ts).

## Архитектура
```
Браузер (Next.js: /, /match, /manager, /contractor/[id], /chat)
   │  POST /api/v1/match          GET /api/v1/match/stream (SSE)      GET /api/v1/contractors
   ▼
NestJS (back/src/matching)
   ├─ FilterService     — сүзгі және воронка (детерминирленген)
   ├─ RankingService    — рет, tie-break id бойынша
   ├─ ExplainerService  — тексерілетін түсіндірме нұсқалары, сыншы, кеш
   └─ LlmClient         — OpenAI немесе MockLlmClient (кілтсіз)
   ▼
PostgreSQL (Prisma): contractors · enrichments · explanation_cache
```

## Қалай тексеру керек (қазылар үшін сценарий)
Барлық сұраныстар кілтсіз жұмыс істейді. Осы мысалдары бар батырмалар `/match` бетінде бар.

| # | Сұраныс | Күтілетін нәтиже |
|---|---|---|
| 1 | Жүргізуші · Алматы · корпоратив · 16.10.2026 · 1 000 000 ₸ дейін | `found`: 4 сәйкес мердігердің 3 карточкасы; воронка 10 → 5 бос → 5 корпоратив алады → 4 бюджетке сыяды |
| 1б | Сол сұраныс 23.10.2026 күніне | Басқа үштік: жүргізушілердің бір бөлігі 23.10 күні бос емес |
| 2 | Флорист · Алматы · үйлену тойы · 15.10.2026 · 300 000 ₸ дейін | `found`, үштен аз: Алматыда барлығы 2 флорист бар |
| 3а | Лайв-бэнд · Астана · үйлену тойы · 14.11.2026 · 1 500 000 ₸ дейін | `no_category_in_city`: Астанада лайв-бэндтер жоқ |
| 3б | Декоратор · Алматы · той · 14.11.2026 · 3 000 000 ₸ дейін | `all_filtered_out`: 3-еуі де 14.11 күні бос емес және ешқайсысы той безендірмейді |

Сол сұранысты MOCK режимінде қайта іске қосу сол ретті және сол мәтіндерді береді. Көрсетілген әр карточканың себебі жеке және күн мен баға туралы тексерілетін ақпаратты қамтиды; сауалнама үзіндісі «со слов подрядчика» деп, ал алмастырылған баға «ценовой ориентир» деп белгіленеді (белгілер сервис қайтарғандай, орыс тілінде көрсетілген). Бос қала/санат пен сүзгілерден кейінгі іріктеу `outcome` өрісінде және жауап мәтінінде ажыратылады.

`/manager` алаң экраны сол іріктеуді қадам бойынша (нақты уақыттағы воронканы) және кестені көрсетеді: түсіндірменің әр фактісі → каталог өрісі → ✓.

## Деректер және интеграциялар
- Каталог: ұйымдастырушылардың датасеті — 66 анонимделген профиль, оның 13-і синтетикалық (`synthetic: true`), 23.09–31.12.2026 аралығындағы бос емес күндер күнтізбесі. [`back/prisma/seed-data/contractors.csv`](back/prisma/seed-data/contractors.csv) файлынан сид арқылы жүктеледі. Карточкаларда синтетикалық профильдер және датасетті дайындау кезінде қойылған бағалар мен қалалар белгіленген.
- Сыртқы API: тек OpenAI (егер кілт берілсе). Сұраныс мысалы (мәндер сервис қабылдайтындай, орыс тілінде):

```http
POST /api/v1/match
Content-Type: application/json

{"city":"Алматы","date":"2026-10-15","eventType":"свадьба","category":"Флорист","budgetKzt":300000}
```
Жауапта `outcome`, `summary`, `criteria`, жеке `reason`, `factsUsed` және деректердің сенімділік жалаушалары бар үшке дейін `cards`, сондай-ақ әр қадамдағы іріктеу себептері көрсетілген `funnel` болады. Жауаптағы мәтіндер сервис қайтарғандай, орыс тілінде беріледі.

- Docker әдепкі бойынша модельсіз жұмыс істейді; тірі модель үшін кілтті орта арқылы беріп, `MOCK=0` орнатыңыз.
- Брондау, төлем, авторизация және хабарламалар жоқ — бұл тапсырмадан тыс.
- Каталог шағын (66 профиль), сондықтан сирек санаттарда үштен азын адал көрсетеміз.

## Жұмыс нұсқасы
Орналастырылған нұсқа жоқ: қазылар жобаны жергілікті түрде бір `docker compose up --build` командасымен іске қосады («Қалай іске қосу» бөлімін қараңыз).
