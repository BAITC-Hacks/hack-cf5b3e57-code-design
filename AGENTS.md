# AGENTS.md — HackAlem AI 2026 · Code & Design

> Читай это первым, каждый раз. Файл — общие правила монорепы. Специфика подпроектов — в `front/AGENTS.md` и `back/AGENTS.md`.

## Задача

Трек 06 «Креативные индустрии», задача #79-lite «Умный подбор подрядчиков» (Firebird). Сервис принимает параметры заказа и возвращает до 3 карточек подрядчиков — с индивидуальным объяснением, почему именно он. Полный SCOPE — [SCOPE.md](SCOPE.md).

Приоритет жюри (цитата): **качество объяснений > честная обработка редких/занятых/пустых категорий > скорость > интерфейс**.

## Продукт

Площадка-агрегатор event-подрядчиков в Казахстане. Каталог + AI-подбор.

### Страницы (front)

| Путь | Что |
|---|---|
| `/` | Каталог всех 66 подрядчиков с фильтрами (город, категория, формат, язык, ценовой диапазон) + CTA «Подобрать с AI» → `/match`. |
| `/match` | Форма умного подбора → до 3 карточек с индивидуальными объяснениями и плашкой исхода. Витрина заказчика из SCOPE. |
| `/manager` | Рабочее место менеджера: форма + таймлайн шагов пайплайна (SSE) + воронка отсева + сравнение с другой датой. |
| `/contractor/[id]` | Детали подрядчика — описание, форматы, календарь, цена. Опционально можно заменить модалкой. |

### Эндпоинты (back), все под `/api/v1`

| Метод + путь | Что |
|---|---|
| `GET /health` | `{ ok, mock }` для проверки и жюри |
| `GET /contractors` | листинг с фильтрами: `city, category, eventFormat, language, priceMin, priceMax, limit, offset`. Возвращает `{ items, total, limit, offset }`. Сортировка `priceFromKzt asc`, tie-break `id`. |
| `GET /contractors/:id` | полный профиль |
| `POST /match` | синхронный подбор → `MatchResponse`. Для `/match`. |
| `GET /match/stream` | SSE стрим шагов пайплайна + финальный `done`. Для `/manager`. |

Справочники (города, категории, форматы, языки) — в [shared/contract.ts](shared/contract.ts) как `as const` массивы. Фронт берёт оттуда, без лишнего endpoint.

## Структура монорепо

```
Hackaton/
├── front/           Next.js (App Router). Никита.
├── back/            NestJS + Prisma + Postgres. Ян + Клод.
├── shared/          API-контракт. Импортится обеими сторонами. НЕ ЛОМАТЬ БЕЗ АПРУВА ОБОИХ.
├── docker-compose.yml   поднимает postgres (5433) + backend (3001)
└── SCOPE.md, AGENTS.md
```

- **`shared/contract.ts`** — единый источник правды для типов запроса/ответа/SSE. Изменение контракта — только через PR с апрувом front и back.
- Никаких «своих» типов, дублирующих контракт.

## Стек

- Next.js (App Router) + TypeScript strict, TailwindCSS.
- NestJS 11 + Prisma 6 + PostgreSQL 16.
- LLM: NVIDIA NIM (OpenAI-совместимый endpoint), ключ в `back/.env` как `NVIDIA_API_KEY`. Без ключа / при `MOCK=1` работает демо-режим (детерминированные шаблоны).
- Демо-запросы, датасет, миграции и сид — в `back/prisma/`. 66 подрядчиков.

## Команды

Из корня (жюри должно поднять всё этим):

```bash
docker compose up --build
# front → http://localhost:3000, back → http://localhost:3001
```

Только Postgres, если разработка локальная:

```bash
docker compose up -d postgres
```

Проверки перед пушем:

```bash
cd back  && npm run build && npx prisma migrate deploy && npx prisma db seed
cd front && npm run lint && npm run build
```

## Ветки и владение

- `main` — интегратор мержит по мере готовности. НЕ работать в `main` напрямую, кроме общей инфры (schema, seed, контракт).
- `develop_yan` — Ян + Клод, бек-логика.
- `nikita/*` — Никита, фронт.
- `ivan/*` — Иван, дизайн, SCOPE, копии.
- Общая инфра (Prisma-схема, миграции, `shared/contract.ts`, docker-compose, сид данных) — коммитим в `main` напрямую, чтобы никого не блокировать.

## Дисциплина коммитов

- Каждый час — по коммиту от каждого. Небольшие, осмысленные.
- Не коммитим секреты. `.env` — только через `.env.example`. `NVIDIA_API_KEY` НИКОГДА не попадает в git.
- Не коммитим полугодовые правки: сначала запустил → проверил → закоммитил.
- Сообщения на английском, императивом.
